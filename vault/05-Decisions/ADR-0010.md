# ADR-0010: Design system berbasis referensi Airbnb dengan primary biru

## Konteks
User memberi referensi visual: design system Airbnb (`npx getdesign@latest add airbnb`), dengan permintaan warna primary diganti biru, bukan pink. Referensi memakai font berlisensi Airbnb dan bertumpu pada foto, sementara MVP tidak punya foto tempat.

## Keputusan
- Pakai gaya referensi Airbnb ([[airbnb-DESIGN]]) sebagai basis: netral, radius, spacing, elevation, pola komponen.
- Primary **#2563eb**, active **#1d4ed8**, disabled **#bfdbfe**, soft **#eff6ff**. Link memakai primary.
- Font **Inter** (bukan Airbnb Cereal yang berlisensi).
- Tidak memakai logo, nama, ilustrasi, atau copy Airbnb.
- Foto diganti ikon kategori, peta, dan blok warna.
- Detail di [[Design-System]].

## Konsekuensi
- Kontras CTA naik dari 3,52 menjadi 5,17 : 1 (lolos WCAG AA).
- Error merah jelas berbeda dari brand.
- Tampilan tanpa foto berisiko terasa kosong → perlu validasi di layar pertama yang dibangun.
