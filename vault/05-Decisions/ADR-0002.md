# ADR-0002: Platform: web responsif + PWA

## Konteks
Opsi: web+PWA, native mobile (React Native/Flutter), atau keduanya. Alur join teman via link harus tanpa install; perencanaan nyaman di layar lebar.

## Keputusan
Satu codebase **web app responsif + PWA** yang bisa di-install ke home screen.

## Konsekuensi
- Teman cukup buka link di browser.
- Offline & push di iOS lebih terbatas dibanding native; MVP hanya offline read-only.
- Tidak perlu publish ke app store.
