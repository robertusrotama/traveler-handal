# ADR-0005: Provider gratis: Gemini + import manual, OSM Nominatim

## Konteks
User tidak punya kredit Claude API (langganan claude.ai terpisah dari API dan tidak boleh dipakai sebagai backend). Google Places butuh billing account. User memilih versi gratis dulu.

## Keputusan
- AI: **Gemini API free tier** sebagai `ItineraryGenerator` utama + **mode import manual** (prompt template → AI di luar app → tempel JSON) sebagai cadangan.
- Verifikasi tempat: **OSM Nominatim** sebagai `PlaceVerifier`.
- Keduanya di balik antarmuka agar provider berbayar (Claude API, Google Places) bisa ditambah via config.
- Hanya konteks perjalanan yang dikirim ke AI (free tier Gemini dapat memakai data untuk pengembangan produk).

## Konsekuensi
- Biaya $0.
- Kualitas AI kemungkinan di bawah model berbayar → verifikasi wajib.
- Nominatim ≤1 req/dtk global, tanpa autocomplete, tanpa rating → rate limiter berbasis DB, tombol Cari, badge verifikasi berarti 'ada di peta'.
- Detail di [[AI-Planner]] dan [[Free-Tier-Limits]].
