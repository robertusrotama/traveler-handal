# ADR-0011: Skill proyek — ponytail & ui-ux-pro-max

## Konteks
User meminta coding memakai skill Ponytail (agar hemat token & efisien) dan UI UX Pro Max (agar desain tidak generik). Keduanya repo pihak ketiga berlisensi MIT.

## Keputusan
- Dipasang di `.claude/skills/` (ikut repo, aktif di setiap session).
- **ponytail** (dietrichgebert/ponytail @96608e0): hanya `SKILL.md` inti, level `full`, menjadi landasan semua pekerjaan kode. Hooks (ledger biaya ke `~/.config`, webhook opsional) dan sub-skill audit/debt/gain/review **tidak dipasang** — tidak dibutuhkan dan menambah side effect.
- **ui-ux-pro-max** (nextlevelbuilder/ui-ux-pro-max-skill @3a13158): skill inti + data + script Python offline (sudah diperiksa: tanpa akses jaringan/eksekusi perintah). Test, skill brand/slides/banner/design tidak dipasang. Path diubah ke `$CLAUDE_PROJECT_DIR`.
- `--design-system`/`--persist` dari ui-ux-pro-max tidak dipakai; [[Design-System]] tetap sumber kebenaran.
- Prioritas: instruksi user > CLAUDE.md/PRD/ADR > skill.

## Konsekuensi
- Kode lebih ringkas; risiko ponytail memangkas hal penting dicegah daftar "tidak boleh dipangkas" di CLAUDE.md.
- Update skill dilakukan manual (salin ulang dari upstream + catat commit di ADR baru).
