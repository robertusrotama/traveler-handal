# ADR-0009: Knowledge base di Obsidian vault dalam repo

## Konteks
User ingin semua pengetahuan proyek tersusun rapi sebagai second memory dalam Markdown. Session AI dimulai tanpa ingatan dan hanya tahu apa yang dibaca.

## Keputusan
Vault Obsidian disimpan di `vault/` di dalam repo dan di-commit bersama kode. `CLAUDE.md` di root mewajibkan membaca `vault/00-Index.md` & `04-Planning/Status.md` di awal session dan memperbarui ADR/dev log/status. PRD & spec ditulis di vault (menggantikan lokasi default `docs/`).

## Konsekuensi
- Setiap session (lokal/cloud) mendapat konteks yang sama.
- Vault bisa basi bila tidak disiplin → aturan update eksplisit di CLAUDE.md.
- `.obsidian/workspace*.json` di-gitignore.
