# ADR-0003: Stack: Next.js + Supabase + Vercel

## Konteks
Dibandingkan: (A) Next.js + Supabase + Vercel, (B) Laravel + Inertia, (C) Next.js + Firebase. Butuh auth anonim untuk guest, data relasional (untuk split bill), realtime, dan minim operasional. User sudah punya akun Supabase & Vercel.

## Keputusan
Pilih **(A)**: Next.js (TypeScript) + Supabase (Postgres, Auth, Realtime, RLS) + Vercel. Detail di [[Tech-Stack]].

## Konsekuensi
- Anonymous sign-in + RLS cocok dengan model hybrid.
- Postgres relasional memudahkan fase 2.
- Supabase free ter-pause setelah ±7 hari tidak aktif (lihat [[Free-Tier-Limits]]).
- Vendor lock-in sedang; Postgres tetap portable.
